# Giám sát bán hàng VinaPhone – VNPT Tây Ninh

Giao diện web (GitHub Pages) cho công cụ giám sát bán hàng tại điểm trọng điểm.
Dữ liệu lưu trên Google Sheet và Google Drive thông qua Google Apps Script (API_URL trong index.html).

- Đăng nhập: Gmail + mật khẩu do Admin khai trong Google Sheet.
- Vai trò: Admin, Lãnh đạo (chỉ xem), Tổ trưởng di động (chỉ thấy đơn vị mình – lọc ở máy chủ).
